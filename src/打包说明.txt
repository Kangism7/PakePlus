考场条码座位打印系统 · APP 打包说明
========================================

一、包里有什么
----------------------------------------
index.html          最终版单文件源码（全部功能已内置，零外部依赖）
icon.png            APP 图标 1024×1024（已生成，可直接选用）
icon.svg            图标矢量源文件（需要换色/改图时用）
pakeplus.config.json  PakePlus 打包配置（项目名、窗口、权限、离线模式等）

二、离线说明（重要）
----------------------------------------
本源码【不加载任何 CDN、不联网请求外部资源】：
- Code128 条码：内置手写绘制，无 JsBarcode 等外部库；
- 导出 PDF：内置手写 PDF 生成器，无 jsPDF；
- 按班级导出 ZIP / CSV：内置手写打包与导出；
- 字体：调用系统自带黑体/宋体/楷体/微软雅黑，断网不缺字。
打包成 APK / EXE 后，断网也能完整使用。

三、用 PakePlus 打包（APK + Windows EXE）
----------------------------------------
1. 电脑安装并打开 PakePlus（官网下载：https://pakeplus.com/）。
2. 新建项目，类型选【本地 HTML 应用 / 离线文件】（不要选网址模式）。
3. 入口文件选择本目录里的 index.html。
4. 图标选择本目录里的 icon.png（1024×1024）。
5. 项目名称填：考场条码座位打印系统；版本号 1.0.0。
   其余参数可对照 pakeplus.config.json 填写：
   - 窗口：宽 1280、高 860，允许缩放；
   - 安卓：开启横屏、存储/文件权限（保存导出的 PDF、CSV、ZIP 必须开）；
   - 离线模式：开启。
6. 打包产物勾选：【Android APK】和【Windows EXE】，同时出包。
7. 点【开始打包】，完成后在输出目录拿到：
   - 考场条码座位打印系统.exe（Windows 免安装，双击直接运行，连打印机打印）；
   - 考场条码座位打印系统.apk（安卓手机安装，桌面图标点开即用）。

四、使用与注意事项
----------------------------------------
1. 安卓首次使用：在系统设置里给本 APP 开启【文件存储权限】，否则导出的 PDF 存不下来；
   导出文件一般保存在手机“下载 / Download”目录。
2. 打印：Windows EXE 版直连本机打印机；安卓端可导出 PDF 后再到电脑打印。
3. 屏幕：横屏预览座位图、门贴更宽敞，配置已默认开启横屏。
4. 后续更新：以后改了功能，重新替换 index.html，再在 PakePlus 里打包一次即可。
5. 本环境不能直接编译 APK / EXE 二进制文件；本包已把源码、配置、图标备齐，
   在 PakePlus 里按上面步骤一键出包。
6. iOS（iPhone / iPad）打包需要苹果开发者证书与苹果电脑，本包不含 IPA，需要时另行处理。

五、已包含的功能对照
----------------------------------------
- 座号条码条：高考标准 50×25mm 粘贴条，条码本体 40×10mm，姓名与考号同行；
- 桌贴：大号桌角座号卡，可选带条码；
- 考场门贴：校名考试 + 超大考场号 + 附座位表；
- 座位布局图：W 型 / S 型 / 直排可切换；
- 纸张：A4 / A3 / B4 / A5 / Letter，或自定义宽高（40–1200mm），行列自由排布或自动排满；
- 字体：黑体 / 宋体 / 楷体 / 微软雅黑；字号缩放 10%–300%；
- 导出：离线 PDF、按班级打包 ZIP、汇总 CSV。
